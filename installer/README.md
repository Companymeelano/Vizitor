# نصب‌کنندهٔ ویندوز ویزیتور — `Vizitor-Setup.exe`

فایل نصب تک‌فایلی سامانهٔ ویزیتور برای **ویندوز ۷ / ۸ / ۸.۱ / ۱۰ / ۱۱**
(۳۲ و ۶۴ بیتی) با رابط فارسی راست‌به‌چپ، آیکن اختصاصی، **انتخاب بخش‌ها با
تیک** و **کد فعال‌سازی**.

| | |
|---|---|
| نام فایل | `release/Vizitor-Setup-1.0.0.exe` |
| حجم | 533٬615 بایت (≈ 521 کیلوبایت) |
| بررسی سلامت | `certutil -hashfile Vizitor-Setup-1.0.0.exe SHA256` (هش در هر ساخت دوباره تغییر می‌کند) |
| موتور | NSIS 3.03 (Unicode) — MUI2 |
| نیازمند | دسترسی Administrator (خود نصب‌کننده درخواست می‌کند) |
| فایل‌های همراه | `install.ps1`، `api/*.py`، `database/*.sql`، بستهٔ فارسی مهاجرت (`android-sql-direct`) |

> ⚠ این فایل داخل سندباکس لینوکس ساخته شده است. ساخت و بسته‌بندی و امضای
> فایل‌ها درست است، اما **اجرای واقعی آن روی ویندوز را باید یک‌بار خودتان
> تست کنید**؛ بخش «چک‌لیست تست» پایین همین فایل را ببینید.

## ۱) بخش‌هایی که تیک می‌خورند (صفحهٔ Components)

| # | بخش | پیش‌فرض | کار آن |
|---|------|---------|--------|
| ۱ | **هستهٔ سامانه — API و سرویس (اجباری)** | ✅ (قفل) | فایل‌های API، سرویس ویندوز `VizitorAPI`، ابزارها، پیکربندی |
| ۲ | پیش‌نیازهای پایتون (pyodbc و درایور ODBC) | ✅ | نصب خودکار pyodbc و درایور ODBC (فقط اگر کم باشد) |
| ۳ | دیتابیس سامانه در SQL Server | ✅ | ساخت دیتابیس/جداول داخلی ویزیتور — کاملاً غیرتلفیقی |
| ۴ | پروکسی IIS روی پورت ۸۰ | ✅ | اجرای API روی پورت ۸۰ بدون دست‌زدن به سایت‌های موجود |
| ۵ | قاعدهٔ فایروال ویندوز برای پورت API | ✅ | باز کردن پورت API تا اپ اندروید وصل شود |
| ۶ | اتصال مستقیم اندروید به SQL Server | ✅ | کاربر محدود `vizitor_android` + گرنت‌های تأییدشده + پورت ۱۴۳۳ فقط برای شبکهٔ محلی |
| ۷ | راهنماها و اسکریپت‌های SQL (بستهٔ فارسی) | ✅ | کپی راهنماها، گزارش نهایی مهاجرت و اسکریپت‌های بازرسی در `docs` |
| ۸ | میان‌بر دسکتاپ و منوی استارت | ✅ | پنل مدیریت، بازرسی و تعمیر، شروع/توقف سرویس، حذف نصب |
| ۹ | بازرسی و تعمیر خودکار پس از نصب | ✅ | چک‌کردن API/دیتابیس/فعال‌سازی/لاگین و تعمیر خودکار (تا ۴ دور) |

هر بخشی را تیک نزنید، همان مرحله در `install.ps1` با سوئیچ متناظر
(`-SkipDatabase`، `-SkipIis`، `-SkipFirewall`، `-SkipPrerequisites`،
`-SkipAndroidPrep`، `-SkipSelfCheck`) رد می‌شود.

## ۲) صفحه‌های نصب‌کننده

1. **خوش‌آمد** — معرفی و تصویر اختصاصی ویزیتور
2. **شرایط استفاده** — متن فارسی
3. **انتخاب بخش‌ها** — همان جدول بالا (تیک‌ها + توضیح هر بخش)
4. **پوشهٔ نصب** — پیش‌فرض `C:\Vizitor`
5. **تنظیمات سرور و دیتابیس** — آدرس/IP سرور (خودکار از شبکه تشخیص داده
   می‌شود)، پورت API، تیک IIS، سرور/پورت/کاربر/رمز SQL Server (رمز با
   `***` نمایش داده می‌شود)، نام دیتابیس سامانه، نام دیتابیس ERP (پیش‌فرض
   `Meelano`) و **پیش‌نمایش زندهٔ آدرس نهایی API**
6. **کد فعال‌سازی** — کد را وارد کنید یا تیک «فعلاً کد ندارم» را بزنید
7. **نصب** — لاگ زندهٔ همهٔ کارها (همان خروجی فارسی `install.ps1`)
8. **پایان** — آدرس API، میان‌بر بازکردن پنل، نمایش `connect.txt`، لینک پوشهٔ راهنما

## ۳) پشت صحنه (چطور به هم وصل می‌شوند)

```
Vizitor-Setup.exe (NSIS)
   ├─ preflight.ps1  →  ip / python / sql / iis / admin / ps  را تشخیص می‌دهد
   ├─ پاسخ صفحه‌ها   →  %TEMP%\<plugins>\answers.ini  (INI ساده، بدون مشکل escape)
   └─ install.ps1 -Answers answers.ini -AppHome <پوشه> [-Skip…ها]
            ├─ پیش‌نیازها، انتشار فایل‌ها، config.json
            ├─ پروکسی IIS (اختیاری) و فایروال
            ├─ provision_sqlserver.py  (جداول سامانه، غیرتلفیقی)
            ├─ provision_android_sql.py (کاربر vizitor_android + گرنت‌ها)
            ├─ سرویس VizitorAPI + بازرسی/تعمیر تا ۴ دور
            └─ connect.txt  (آدرس API و مشخصات، بدون رمز)
```

`install.ps1` همان نصب‌کنندهٔ هوشمند قبلی است و بدون هیچ پارامتری هنوز
دقیقاً مثل قبل و کاملاً پرسشی کار می‌کند؛ پارامترهای جدید فقط برای زمانی
است که نصب‌کنندهٔ گرافیکی آن را صدا می‌زند.

## ۴) امنیت

* **رمز SQL Server هیچ‌جا نمایش داده نمی‌شود**: در صفحهٔ مخصوص با `***`
  گرفته می‌شود، در `answers.ini` موقت است، بعد از نصب همان فایل پاک
  می‌شود و در لاگ‌ها/گزارش‌ها/خطاها چاپ نمی‌شود.
* رمز اتصال مستقیم اندروید به‌صورت خودکار ساخته می‌شود و فقط در
  `C:\ProgramData\Vizitor\android_app_password.txt` با ACL محدود
  (SYSTEM + Administrators) ذخیره می‌شود؛ فقط مسیر فایل چاپ می‌شود.
* پوشهٔ `C:\ProgramData\Vizitor` (که `config.json` و رمز دیتابیس در آن است)
  در پایان نصب ACL محدود می‌گیرد.
* قاعدهٔ فایروال پورت ۱۴۳۳ فقط برای `LocalSubnet` باز می‌شود (نه اینترنت).
* رفتار دیتابیس **غیرتلفیقی** است: فقط `CREATE … IF NOT EXISTS`؛ هیچ
  `DROP`/`TRUNCATE`/`ALTER` روی اشیای موجود، و هیچ تغییری در تنظیمات سرور.

## ۵) مسیرهای نصب

```
C:\Vizitor\                ← پوشهٔ نصب (AppHome؛ قابل تغییر در ویزارد)
├─ setup\                  ← بستهٔ اصلی: install.ps1، api\، database\، preflight.ps1، connect.txt
├─ tools\                  ← میان‌برهای bat: بازرسی، شروع/توقف سرویس، پنل، اتصال مستقیم SQL
├─ docs\                    ← راهنماهای فارسی + docs\migration (کل بستهٔ android-sql-direct)
├─ api\ iis\ run.bat       ← برنامهٔ منتشرشدهٔ API (توسط install.ps1)
└─ uninstall.exe
C:\ProgramData\Vizitor\    ← config.json، vizitor.log، vizitor.pid، android_app_password.txt
```

## ۶) حذف نصب

`uninstall.exe` (یا «برنامه‌ها و ویژگی‌ها») این کارها را می‌کند:
توقف و حذف سرویس `VizitorAPI`، حذف قاعده‌های فایروال `Vizitor API` و
`Vizitor SQL 1433`، حذف سایت/اپلیکیشن IIS **فقط اگر خود ویزیتور ساخته
باشد**، حذف میان‌برها و فایل‌های برنامه.
از شما می‌پرسد که `C:\ProgramData\Vizitor` هم پاک شود یا نه — و
**داده‌های دیتابیس در هر حالت دست‌نخورده می‌مانند** (هیچ جدولی حذف نمی‌شود).

## ۷) ساخت دوبارهٔ فایل نصب

**روی ویندوز:**
```
1. NSIS 3 را نصب کنید:  https://nsis.sourceforge.io/Download
2. در ریشهٔ مخزن اجرا کنید:   installer\build.bat
3. خروجی:  release\Vizitor-Setup-1.0.0.exe
```

**روی لینوکس/CI:**
```
sudo apt install nsis        # یا NSISDIR=/opt/nsis
./installer/build.sh
```

آیکن و تصاویر ویزارد از `installer/assets/` می‌آیند و با
`python3 installer/assets/make_branding.py` بازتولید می‌شوند
(`vizitor.ico` چند-اندازه: ۱۶ تا ۲۵۶ پیکسل).

## ۸) نصب بی‌صدا (اختیاری، برای مدیر سیستم)

```
Vizitor-Setup-1.0.0.exe /S
```
در حالت بی‌صدا همهٔ صفحه‌ها رد می‌شوند و `install.ps1` با مقادیر پیش‌فرض
(IP شناسایی‌شده، `localhost`/`1433`، کاربر `sa`، دیتابیس `vizitor`) اجرا
می‌شود. اگر حساب `sa` رمز داشته باشد، این حالت مناسب نیست — از حالت
گرافیکی استفاده کنید.

## ۹) چک‌لیست تست (لطفاً یک‌بار روی سرور انجام دهید)

- [ ] فایل روی ویندوز ۷ و ویندوز ۱۰/۱۱ اجرا می‌شود و UAC می‌پرسد.
- [ ] آیکن فایل و آیکن نصب‌شده، آیکن ویزیتور است.
- [ ] متن‌های فارسی درست و راست‌به‌چپ دیده می‌شوند (بدون علامت سؤال).
- [ ] آدرس IP سرور در صفحهٔ تنظیمات خودکار پر شده است.
- [ ] صفحهٔ بخش‌ها تیک‌ها را نشان می‌دهد و می‌شود خاموش/روشن کرد.
- [ ] کد فعال‌سازی ثبت می‌شود (یا «بعداً» کار می‌کند).
- [ ] در پایان: «همه بازرسی‌ها پاس شد» سبز است و آدرس API نشان داده می‌شود.
- [ ] صفحهٔ وب `http://<IP>:<port>/api/health` در مرورگر جواب می‌دهد.
- [ ] میان‌بر «بازرسی و تعمیر» کار می‌کند.
- [ ] حذف نصب، سرویس و قاعده‌های فایروال را پاک می‌کند و دادهٔ دیتابیس را
      دست نمی‌زند.
- [ ] اگر بخش «اتصال مستقیم اندروید» تیک خورده باشد: کاربر
      `vizitor_android` در SQL Server ساخته شده، پورت ۱۴۳۳ فقط برای
      شبکهٔ محلی باز است و فایل رمز با دسترسی محدود وجود دارد.

اگر جایی خطا دید، خروجی کامل پنجرهٔ لاگ نصب را بفرستید — همان متن،
دقیقاً همان چیزی است که برای رفع مشکل لازم است.

## ۱۰) عیب‌یابی سریع

| نشانه | راه‌حل |
