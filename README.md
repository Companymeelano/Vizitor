# G1 Z4 Control Pro

کنترل هوشمند سیستم امنیتی برای **Classic Z4 / Z4 Ultra + G1** از مسیر واقعی پیامک گوشی.

این برنامه ماکاپ نیست و محصول رسمی شرکت کلاسیک هم نیست. هر وضعیتی که سخت‌افزار گزارش نکرده باشد «نامشخص» می‌ماند. قابلیتی که در پروتکل منتشرشده نیست با «پشتیبانی نمی‌شود» نشان داده می‌شود، نه با یک دکمه ساختگی.

## چه کار می‌کند

- فعال‌سازی و غیرفعال‌سازی، فقط به‌صورت پالس خروجی نقشه‌شده. در سیم‌بندی استاندارد: خروجی ۲ و خروجی ۳. موفقیت پالس، وضعیت خود پنل را فعال‌شده نشان نمی‌دهد.
- استعلام `*رمز*01`، توقف شماره‌گیری `*00`، کنترل خروجی‌های آزاد، درخواست شارژ `*80`، ذخیره فرمول `*81`، و چهار قالب افزایش اعتبار.
- هشدار پیامکی زون، آژیر، برق، قطع خط و اختلال، اگر متنش واقعاً برسد.
- چند دستگاه، رمز برنامه، اثر انگشت، چهار پوسته، تاریخ جلالی، رقم فارسی، ویجت وضعیت ذخیره‌شده.

## چه کار نمی‌کند

نیمه‌فعال، یادگیری ریموت، دانلود ۲۰۰ رویداد G1، ولتاژ باتری، شروع آژیر، و ری‌استارت پنل فرمان پیامکی ندارند. جزئیات و منابع در [`G1_Z4_PROTOCOL_SPECIFICATION.md`](G1_Z4_PROTOCOL_SPECIFICATION.md) است.

معماری، امنیت و شمای داده: [`ARCHITECTURE.md`](ARCHITECTURE.md) · [`SECURITY.md`](SECURITY.md) · [`SCHEMA.md`](SCHEMA.md)

## ساخت

Android Studio یا خط فرمان، JDK 17، Android SDK 35.

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease
```

اگر `keystore/release.jks` وجود داشته باشد، نسخه انتشار با نام مستعار `g1z4` و گذرواژه `g1z4-control-pro` امضا می‌شود. این گذرواژه برای ساخت تکرارپذیر در مخزن آمده است؛ قبل از توزیع عمومی عوضش کنید.

گردش‌کار GitHub Actions روی `ubuntu-latest` با Temurin 17 تست را اجرا می‌کند، هر دو APK را می‌سازد، و در `release/` می‌گذارد:

- `release/g1z4-control-pro-debug.apk`
- `release/g1z4-control-pro-release.apk`

شناسه برنامه: `ir.g1z4.controlpro`. کمینه اندروید ۸.

## مجوزها

ارسال، دریافت و خواندن پیامک فقط برای مسیر G1. اینترنت حذف شده است. بدون مجوز ارسال، فرمان در نسخه انتشار «دسترسی ارسال پیامک فعال نیست» می‌ماند و چیزی فرستاده نمی‌شود.

## حالت آزمایشی

فقط در بیلد دیباگ، بعد از هفت لمس روی ردیف درباره، و با تأیید صریح. پاسخ‌ها برچسب «آزمایشی» دارند و وارد وضعیت سخت‌افزار نمی‌شوند. نسخه انتشار این حالت را ندارد.

## آزمون‌ها

`app/src/test` فعال‌سازی، غیرفعال‌سازی، استعلام، آژیر، زون، برق، باتری، پاسخ نامعتبر، مهلت، رد مجوز، و دو دستگاه را روی پروتکل می‌سنجد. این‌ها جایگزین آزمون روی پنل واقعی نیستند.
